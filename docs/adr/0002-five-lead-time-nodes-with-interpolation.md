# 时效节点从 17 减到 5，缺失节点用参数时空插值生成

GEFS Reforecast 仅 00Z 起报（实测约束），可达时效节点由 v5.7 的 17 个/季（最高温 9 + 最低温 8，68 模型/站）缩减为 **5 个/季**（最高温 {54,30,6}h + 最低温 {48,24}h，20 模型/站）。

对缺失节点（如最高温 48h），不再用「方差乘系数」这类主观缩放，改为在相邻已训练节点的 EMOS 参数 (a,b,c,d) 间做线性插值；最低温短时效（<24h）借用 24h 参数并对标准差按 √(L/24) 做物理收缩。插值模型须通过留出节点验收（CRPS ≤ 1.05×真实 + PIT p>0.05）。
