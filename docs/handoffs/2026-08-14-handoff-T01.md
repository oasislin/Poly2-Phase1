## 5. 关键技术决策（实现时必须遵守）

- **包名是 `herbie-data`**（PyPI 的 `herbie` 是无关的 Django 项目，切勿使用）
- **变量**：`tmax_2m`（6h 窗口 TMAX，reforecast 文件里是 `X-Y hour max fcst` 消息）；`tmin` 属于 T02
- **成员**：本轮参数化即可（如 `members=[0]`）；5 成员（c00+p01-p04）协议属于 T02
- **裁剪**：`region_bounds` 给定即裁剪（上海 25-35N/115-125E）；0-360°/±180° 环绕的完善属于 T03，T01 做基础裁剪即可
- **网络全部 mock**：测试用 `monkeypatch` 替换 `gefs_fetcher.Herbie`，不触碰 AWS
- **缓存/重试/MD5 属于 T06**，本轮**不要**提前实现
- **Herbie API 参考**：`Herbie(date, model="gefs_reforecast", member=0, fxx=0, variable_level="tmax_2m", save_dir=..., verbose=False)`；`H.download(search=...)` 与 `H.xarray(search=..., engine="cfgrib")`
